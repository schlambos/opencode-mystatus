## FIX (2026-07-30) — register mystatus:ping IPC handler
Bug: preload exposed window.mystatus.ping() → ipcRenderer.invoke("mystatus:ping")
but main never registered ipcMain.handle for that channel. Bridge ping always
rejected; UI showed "error".

Fix:
- Extracted CHANNELS = { ping, push } into src/shared/ipc.ts.
- src/main/index.ts: added registerShellIpc(ipc) exporting the handler
  registration; called inside app.whenReady() before createWindow().
- src/preload/index.ts: uses CHANNELS.ping / CHANNELS.push.
- src/main/index.test.ts: replaced tautological test with a real unit test
  that mocks electron.ipcMain, calls registerShellIpc, and asserts the ping
  handler is registered on CHANNELS.ping and returns "pong". Also asserts
  the shared channel name constants.
- Moved `const isDev = !app.isPackaged` inside createWindow() so importing
  the module under test (mock provides only ipcMain) does not crash at
  top-level.
- Guarded bootstrap() with process.env.VITEST check so the real Electron
  app lifecycle does not run under vitest.
