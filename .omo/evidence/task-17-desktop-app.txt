Acceptance criteria (vitest, pure decision function — no Electron needed):
  - no notification on baseline poll
  - exactly one on crossing (was >= threshold, now < threshold)
  - none on repeated sub-threshold polls inside cooldown
  - one on recovery (was < threshold, now >= threshold)
  - none for hidden/disabled providers
  - error model preserves state, fires nothing
  - threshold boundary (25) treated as not-below (mirrors plugin/mystatus.ts:7346)
  - cooldown suppresses crossed but NOT recovered
  - first observation of a new key is baseline (no notification)
