## Root-cause fix to the existing scaffold (preload did not load)
- First real window launch surfaced a latent bug: the preload was built as
  ESM (.mjs with import statements) but the window runs sandbox: true.
  Sandboxed preload can only execute CommonJS, so the preload threw
  "Cannot use import statement outside a module", window.mystatus was
  undefined, and the renderer crashed (blank #root). Todo 1/2 had never
  launched a renderer that actually uses the bridge, so it went unnoticed.
- Fix (security posture preserved): preload is now the one target built as
  CJS (electron.vite.config.ts preload output format:"cjs", entry .js);
  main/index.ts preload path .mjs → .js. Verified out/preload/index.js is
  CJS ("use strict"; const electron = require("electron")).
- Hardened the boundary: getBridge() returns undefined when preload is
  absent; connectStatusStore degrades instead of white-screening (covered
  by a unit test).
