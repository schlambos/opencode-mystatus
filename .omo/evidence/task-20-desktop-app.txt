## Design
- Prefs file: ~/.config/opencode/mystatus-desktop.json (matches plugin's configFile dir)
- Holds ONLY desktop concerns: { threshold, trendMode, notifications, notifyCooldownMin,
  lastTab, windowBounds, launchAtLogin } — NO MyStatusConfig keys, NO credentials
- Defaults: threshold=25, notifications=true, notifyCooldownMin=60, launchAtLogin=false,
  trendMode/lastTab/windowBounds=undefined
- Atomic write: writeFileSync(<file>.tmp, mode 0o600) → renameSync(<file>.tmp, <file>)
- Corrupt JSON on load → catch → return DEFAULT_PREFS (no throw, file left in place)
- coerce() defensively normalizes any field type back to defaults (invalid trendMode,
  non-boolean notifications, non-number threshold, etc.)
- Single-instance lock acquired BEFORE any window creation; on failure app.quit();
  second-instance event restores+focuses the existing window
